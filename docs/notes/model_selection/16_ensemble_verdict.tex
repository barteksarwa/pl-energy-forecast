LEAR+CQR, Chronos+CQR (best FM). Weights: inverse trailing-60-day
crps3, past-only, equal-weight warm-up. Mechanics in learning

\subsection{The over-coverage fix}

The raw blend covered 84.2\% (nominal 80\%): averaging three
calibrated bands over-widens because member errors are not
perfectly correlated. A second rolling-CQR pass on the blended band
fixed it: 79.9\% coverage, Winkler 85.2 $\rightarrow$ 84.7, MAE
untouched. Cost: spike coverage 57.4\% $\rightarrow$ 55.3\%
(still above the champion's 51.3\%).

\subsection{Verdict}

\textbf{\texttt{ens\_crps\_cqr} is the promotion candidate for the
price product.} MAE 17.34, rMAE 0.620, coverage 79.9\%,
Winkler 84.7. Every number beats or matches the standing champion.

\subsection{Honest caveats}

\begin{itemize}
\item Skill weighting adds only 0.12 MAE over equal weights.
      The diversity does the work, not the weighting cleverness.
\item Spike MAE 61.1 --- marginally worse than the champion's 60.3.
      The blend smooths; spikes resist smoothing.
\item TFT excluded from this table (its stored preds cover a
      different window --- two-window discipline).
\end{itemize}
